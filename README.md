# Ferramenta-de-controle-de-investimento
Utilizando uma planilha do excel para fazer simulações de investimento de FII
Quanto investir por mês: Célula D15
Por quantos anos: Célula D16
Qual a taxa de rendimento mensal: Célula D17
Quanto de patrimônio vai acumular: Célula D18
Quanto vai receber de dividendos por mês: Célula D19

VF: Entra no calculo para retornar um investimento futuro com bases no valores, utilizamos o valor da taxa de rendimento mensal, quantos anos investir (Devemos multiplica por 12 pois é quantidade de meses em um ano), quantidade a ser investida por mês e multiplicar por -1 para deixar o número positivo.

PROCV: Retorna um valor de uma lista vertical, nessa planilha é usado para buscar a porcentagem de cada tipo de FII.

Sem intervalos nomeados devido a ser utilizado o excel 365 online, pois nessa versão não estava disponível.

Os percentuais de cada perfil vem de uma planilha de apoio onde está concentrado os dados de cada perfil e utilizando o PROCV esses valores foram puxados para planilha de controle de investimento.

Foi adicionados os gráficos do tipo de pizza e uma nova simulação utilizando a sugestão de investimento de 30% do salário.
